# CIC Atlas · 切片标注工作台

中文 H&E 阅片、CIC 结构标注和已有 HER2ST 空间结果对照。

**使用网页：<https://weigenwu.github.io/CIC/>**

## 开始使用

1. 选择 H1、D6、E1、F1 或 G1。五张原图已内置，不用重新上传。
2. 滚轮缩放，空格 + 拖动平移；`R` 选红箭头，`B` 选蓝箭头，按住鼠标从箭尾拖向目标位置，松开完成；`P` 沿用当前颜色。单击不新增箭头。每支箭头计 1，下方状态栏及“标注”面板分别显示本片红、蓝及合计。`E` 拖出椭圆，`G` 逐点画轮廓、`Enter` 完成。新标注默认“疑似 CIC”。
3. 在“标注”面板填写标注者、确认/疑似/排除、置信度、内细胞数量和形态依据；可独立绘制外细胞和多个内细胞轮廓。
4. 左侧切到“空间表达”标签，打开叠加，按高到低或低到高排序，点击 spot 或“下一个表达位置”，直接放大到原图位置。支持病理区域筛选。关闭叠层可清楚查看 H&E。
5. 导出 JSON 作为可恢复的完整备份；CSV 用于后续空间分析；GeoJSON 保存原图轮廓。PNG 是当前显示视野，并有配套坐标 JSON。
6. 选好切片后点击 **专注阅片**，隐藏侧栏并铺满网页；点击 **全屏** 进入系统全屏。窄工具条保留切片、颜色、撤销、删除和表达叠层；底部状态栏实时计数。点击“退出专注”恢复面板。画布获得焦点时 `Tab` 切换专注；`Esc` 先取消绘制，无绘制时退出专注。切换布局保持当前视野中心与倍率。

红／蓝是自定义分组，与确认／疑似／排除标签独立。箭头采用细线和开放箭头尖端。浏览工具 `M / V` 和箭头工具 `P / R / B` 中，拖动已有箭头的线身可整体移动；选中后拖动两端小方框可改变长度和方向。`Esc` 取消本次拖动；完成后可用 `Ctrl+Z` 撤销。

箭头尖端存储为原图 `point` 坐标，手绘箭尾保存在 `geometry.tail=[x,y]`；长度随图像缩放，线宽保持清晰。旧版点标记的坐标与标签保留，缺省颜色为红色，拖动编辑后保存两端位置。最近 spot 仍由尖端计算。“标注”面板可改色。移动、调整、改色不增加计数；附属内外细胞轮廓保持其原图位置。

`1 / 2 / 3` = 确认 / 疑似 / 排除；`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 重做；`Delete` 删除所选；`H` 隐藏标注；`F` 全图。删除可撤销。

“已有视野与待复核书签”内含 20 个历史视野、两处歧义书签、顺序视野巡查及已阅视野记录。书签不会自动变成 CIC。已阅区域可能重叠，不能当作无 CIC 阴性区域或精确覆盖率。

## 阅片布局与导航

参考 [QuPath 的阅片操作](https://qupath.readthedocs.io/en/stable/docs/starting/viewing.html)，采用一个可收起的侧栏，包含“切片 / 标注 / 空间表达”标签。工具条固定在画布上方；右上角总览图支持点击和拖动定位。打开多个面板不会挤占两侧图像空间。

- `M / V` 移动工具；滚轮围绕鼠标位置缩放；空格按住时临时平移。
- 画布中方向键移动视野；`Shift + ↑ / ↓` 缩放；选中标注后 `Enter` 打开属性。
- 下方显示当前比例，并可一键切换 25%、50%、100%、200%、400% 或全图。
- 像素标尺随缩放更新。100% 表示一原图像素对应一 CSS 像素；没有物理尺寸校准时，不把显示比例标为 20× / 40× 物镜倍数或微米。
- 标记、导出和已有空间表达沿用原始坐标；本次布局调整不改变原图或标注数据结构。

## 接入的原有空间分析

五张切片共 **2,647 spots**：H1 613、D6 315、E1 587、F1 691、G1 441。

| 图层 | 口径 |
|---|---|
| PIEZO1、ERBB2、CDH1、TJP1 | log2(1 + counts / library_size × 10⁶)，沿用既有表，零值表示测序未检测，不证明生物学无表达 |
| HER2 扩增子、细胞连接、皮质收缩相关程序 | 原分析 UCell 评分 |
| CIC 相关转录评分 | 原来固定签名的分数，不是已观察到的 CIC |
| HER2 高 / CIC 评分高联合区域 | 原分析残差分组，不按本网页重新定义阈值 |

颜色使用**当前切片内全部 spots 的最小–最大值**；跨片颜色不可直接定量比较。原图左上角为 `(0,0)`，x 向右、y 向下，保留小数像素。所有叠层使用原始 `pixel_x/pixel_y`，没有通过截图反推坐标。

病理分区沿用既有表：H1、E1、F1 有分区标签；D6、G1 的既有表为 `NA`，不能自动筛出肿瘤区。

### 五张为什么入选

依据既有 HER2 扩增子活性与 CIC 转录评分的组成校正关联、联合高值区域和组织覆盖，每位患者一张：H1、D6、E1、F1、G1。**并非按人工 CIC 数量、形态清晰度或 PIEZO1 结果优选。**这五张是富集的可行性探索集，不是独立随机验证集。

表达导航用于寻找候选结构。若要检验“高表达区域更常出现 CIC”，应预定义对照区域和搜索范围，纳入同片低表达/匹配区域，保留患者层级分析。spot 是多细胞表达采样单位；最近 spot 不代表捕获归属，不能给内/外细胞分配表达。网页不自动判断 CIC，也不从 H&E 推断细胞身份或具体形成机制。

### 表达阅片记录

显示图层、排序或 spot 详情会永久记录该切片接触过的指标（当前项目内）。关闭叠层、撤销、重新导入不移除记录。`created_blinded` 记录新建时状态；`blinded_to_spatial_scores` 保守反映该项目是否对该片显示过表达。此字段仅记录工具内行为，不能保证标注者未在其他软件看过表达。

## 数据保存与导出

- **标注保存在此浏览器**（localStorage），不上传服务器，也不会自动写回 GitHub。定期导出 JSON；清除站点数据、换浏览器/设备/网址不会自动同步。
- 如果浏览器拦截自动下载，可在导出窗口点击生成的“保存”链接。
- 本地 JPEG/PNG/WebP 可多选导入，以 SHA256 标识原图；文件保存在本机 IndexedDB。JSON 不包含本地图片本身；跨设备继续时重新选择同一原图。内置五片随网页提供。
- JSON 导入先完整校验尺寸、校验和、标签、坐标和轮廓，再合并；同编号不同内容会拒绝，避免覆盖。原始项目不受无效文件影响。
- 多窗口同时写入时暂停后收到更新窗口的写入，提示导出并刷新。不要同时在多个窗口编辑同一项目。
- CSV 包含全部标签，统计时明确筛选 `definite_CIC` 等；`nearest_spot_*` 为最近中心的背景表达，`cell_gene_assignment=NOT_ASSIGNED`。
- JSON 保留 `markerColor` 和手绘箭头的 `geometry.tail`；CSV 包含 `marker_color`、`arrow_count`（箭头为 1，轮廓为 0）、`arrow_tail_x_px`、`arrow_tail_y_px`。GeoJSON 主结构仍为尖端 Point，并以 `arrow_tail_px` 属性保存箭尾；附属内外轮廓不重复计数。
- GeoJSON 是**图像像素坐标**，不是地理经纬度；每个 feature 带 section 和 role。用于外部阅片软件前按切片拆分并确认坐标约定。本项目不声称已在 QuPath 验证导入。
- 原图未做增强、去噪或 AI 重建；仅导航缩略图缩小。画布放大不增加原图信息。

## 开发、测试与发布

无前端依赖和构建步骤，`dist/` 是完整静态网站。需要 Python 3 和 Node.js 22+ 执行本地验证。

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory dist
npm run check
npm test
```

然后打开 <http://127.0.0.1:8765/>。不要用 `file://` 双击打开（浏览器会阻止模块/数据加载）。

从原 CIC 工作区重新整理数据：`python scripts/prepare_data.py --workspace /path/to/CIC`，需 Pillow。此脚本读取原表，审计坐标，按 SHA256 核对并复制原 JPEG；不重跑分析、不覆盖原数据。`dist/data/manifest.json` 记录来源表相对路径和校验和。

GitHub Pages 使用 **Deploy from a branch**，发布分支为 `codex/pages` 的根目录；`main` 保留完整代码，`dist/` 是发布源。自定义 Actions 任务在首次发布时因账户账单锁定无法启动，已改用成功验证的静态分支发布。内置 Pages 构建与部署成功。

后续修改经检查并提交到 `main` 后，在 PowerShell 运行 `./scripts/publish.ps1`，脚本会测试、上传代码、将 `dist/` 同步到静态分支并请求发布。不覆盖远端历史、不自动提交未审阅文件。需要已登录的 Git 和 GitHub CLI。

测试覆盖坐标缩放还原、两处已审核书签的最近 spot、五张原图哈希、全部 spot 坐标、项目恢复及导入冲突、内外轮廓和 CSV 转义。

## 数据来源与署名

H&E 图像和基础表达数据来自 **Andersson et al., Spatial deconvolution of HER2-positive breast cancer delineates tumor-associated cell type interactions**，公开数据集 [Zenodo 4751624](https://doi.org/10.5281/zenodo.4751624)，**CC BY 4.0**。论文：[Nature Communications (2021)](https://pmc.ncbi.nlm.nih.gov/articles/PMC8516894/)。原始 JPEG 保持逐字节一致。网页复用了本项目的衍生评分和已有 spot 表，未改变原始像素。

此仓库包含五张公开数据图像、衍生空间数据和网页代码。没有包含用户其他研究文件或新产生的人工标注。
